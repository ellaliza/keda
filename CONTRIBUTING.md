# Contributing to Keda

Keda is a hobby project, and I'm building it myself on purpose: writing the ORM
is the point of the project. Because of that, **I'm not accepting pull requests
with code changes right now.**

You're still very welcome to help in other ways:

- **Open an issue** if you find a bug, hit confusing behaviour, or spot
  something in the documentation that is wrong or unclear. Include the Python
  version, a minimal snippet that reproduces the problem, and what you expected
  to happen.
- **Share ideas** in an issue. Suggestions are appreciated, but I may not
  implement them, or may implement them in my own way.
- **Fork it.** The project is MIT licensed, so you're free to take it in your
  own direction. See [LICENSE](LICENSE).

Documentation fixes (typos, wording) are the one kind of pull request I'm happy
to look at.

If this policy changes, this file will be updated.
